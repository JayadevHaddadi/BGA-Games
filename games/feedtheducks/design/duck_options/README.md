# Feed the Ducks: duck design options

Colours match the game (white #f4f1ea, green #2e9d3a, red #d63a34, blue #2a62d6). Files: `duck_<style>_<colour>.svg`; overview in `duck_options.png`. No drop shadows. `make_ducks.py` regenerates the SVGs.

- A Rubber duck: round side-view bath duck, big eye, orange beak, shine highlights.
- B Kawaii chibi: front-facing blob, huge glossy eyes, pink blush, tiny wings.
- C Geometric + symbol: flat top-down shapes with a big circle/square/triangle/diamond on the back for colour-blind play.
- D Swimming: top-down duck with ripple rings and a wake, folded wings.
- E Accessories: rubber duck with sailor hat (white), sunglasses (green), bow (red), crown (blue).
- F Felt plush: side-view duck with fuzzy felt texture, cross-stitch pattern and dashed stitching.
