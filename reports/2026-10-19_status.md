## 2. Process observations

- **Studio is never exercised before review.** Nothing here runs the PHP inside the framework; the Microchip crash would have been the first thing a reviewer saw. A live table at 2 and max players (refresh, zombie, finish, replay) belongs before every alpha request.
- **Deploy gaps.** The old workflow deployed only `HEAD~1..HEAD`, so multi-commit pushes skipped games (Microchip was never deployed). Fixed: `tools/sync.py --changed`.
- **Sync deletes.** `sync.py` mirrors the folder and deletes Studio files missing locally; the docs said the opposite. Mandala is now upload-only.
- **Shared Linux checkout.** One session's uncommitted `tools/sync.py` edit blocked other sessions' pulls; a pull stashed the Red session's work (`stash@{0}` on the Ubuntu machine).
- **Repository weight.** Tracked binaries: `antigravity_chats_export.zip` (45 MB), `games/microchip/Microchip.zip` (5 MB), People STL files, a duplicate `games/red/RED_EN.pdf` next to `games/redd/`.
- **Local clone health.** 24 objects were missing on the Windows clone; repaired with `git fetch --refetch`.
- **Reply in the request thread.** BGA only sees answers sent as replies to the alpha request mail (their 15 Oct note).
